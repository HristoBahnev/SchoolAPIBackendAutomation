SchoolAPIBackendAutomation
==========================

SchoolAPIBackendAutomation is an automated testing suite for the School API backend, utilizing C#, RestSharp, and Reqnroll to validate RESTful endpoints for roles such as Admin, Teacher, Student, and Parent.​

🚀 Features
-----------

- ✅ BDD test structure using [Reqnroll](https://reqnroll.dev/)
- ✅ Modular API services (`AdminApi`, `TeacherApi`, `ParentApi`, etc.)
- ✅ Shared test context via `ScenarioContext`
- ✅ Centralized utilities for assertions and logging
- ✅ ExtentReports for detailed HTML reporting
- ✅ NLog-based logging per test run

🧪 Getting Started
------------------

### Prerequisites

*   .NET SDK (version 6.0 or later)
    
*   Visual Studio or JetBrains Rider
    
*   Access to the School API backend​
    

### Installation

1.  Clone the repository https://github.com/HristoBahnev/SchoolAPIBackendAutomation.git
    
2.  Open the solution in your preferred IDE.
    
3.  Restore NuGet packages.​
    

### Running Tests

*   Using Visual Studio Test Explorer:
    
    *   Build the solution.
        
    *   Open Test Explorer and run all tests.
